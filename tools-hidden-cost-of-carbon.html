This is a conversation-starter, not a compliance-grade model. It combines a single grid factor, a single fuel factor, and one carbon price into one number - it doesn't account for sector benchmarks, CBAM, country-level tax regimes, or exemptions. Default figures live in FALLBACK_DATA near the top of the script and should be reviewed every few months. To try live pricing, use "Refresh data" - if it can't reach a source (offline, blocked, source down), it silently falls back to the numbers above.
